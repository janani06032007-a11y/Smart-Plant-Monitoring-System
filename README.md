# Smart-Plant-Monitoring-System
Smart Plant Monitoring System using Arduino UNO and soil moisture sensor
## 📌 Project Overview

The Smart Plant Monitoring System is a beginner-friendly Arduino project designed to monitor soil moisture and indicate whether the plant needs water.

The system uses a soil moisture sensor to detect the moisture level of the soil. An LED and buzzer provide an alert when the soil becomes dry.

## 🔧 Components Used

- Arduino UNO
- Soil Moisture Sensor
- LED
- Buzzer
- Resistor
- Connecting Wires

## ⚙️ Working

1. The soil moisture sensor measures the moisture level.
2. Arduino UNO reads the sensor value.
3. The moisture value is compared with a predefined threshold.
4. If the soil is dry, the LED and buzzer are activated.
5. If the soil has sufficient moisture, the system remains in the normal condition.
